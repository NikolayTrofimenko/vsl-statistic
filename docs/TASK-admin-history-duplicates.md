# ТЗ: история загрузок, статистика только для админа, удаление и «Это повтор»

Статус: согласовано с Колей 2026-10-15, к реализации. Контекст проекта — `CLAUDE.md`.

## 1. История загрузок (только админ)
- Новая страница/вкладка «История загрузок», видна и доступна только `admin` (проверка на сервере через `adminOnly()`).
- Сводка по месяцам: сколько крео добавилось, с разбивкой по вертикалям; выбор месяца/периода.
- Список добавлений за период: ID крео, вертикаль, гео, дата, **источник** (загружено через сервис / появилось на Drive напрямую), **кто загрузил** (для загрузок через сервис).
- «Когда добавилось» = `first_seen_at` (момент появления в библиотеке); для загрузок через сервис записывать `uploaded_by` (user id) — новая колонка, миграция. Для уже существующих крео источник «Drive», загрузивший неизвестен.

## 2. «Качество на лендах» — только админ
- Вкладка и все каналы `stats:*` — только `admin`: скрыть пункт меню, guard на маршрутах `/quality*`, на сервере добавить `stats:` в `adminOnly()`.
- Сбор данных трекером (`/api/collect`, `/t.js`) — без изменений, публичный.

## 3. Удаление крео (только админ)
- Кнопка «Удалить» в карточке/диалоге крео, с подтверждением («Удалить SUS-0142? Файл уйдёт в корзину Google Drive»).
- Действие: файл перемещается **в корзину Google Drive** (`files.update trashed=true`, восстановим 30 дней) и исчезает из библиотеки. Запись в базе помечается удалённой (кем, когда), не стирается — ID крео больше никому не выдаётся. Синхронизация не должна вернуть его обратно (Drive уже не отдаёт `trashed`).
- Если Drive вернул ошибку (нет прав и т.п.) — показать её, крео не скрывать.
- Удалённые видны в «Истории загрузок» с пометкой «удалён».

## 4. «Это повтор» (все роли)
- Кнопка «Это повтор» на карточке/в диалоге. Опционально — поле «повтор какого крео» (ввод ID, например `SUS-0087`), с проверкой, что такой ID существует.
- Отметка хранит: кто, когда, ID оригинала (если указан). Один пользователь — одна отметка на крео; можно снять свою.
- Админ видит: счётчик «Отмечены как повтор: N» и фильтр/список таких крео с кем отмечено и оригиналом (можно открыть рядом). Действия админа: «Удалить» (п. 3) или «Не повтор» (снять все отметки).
- Баер видит у крео только свою отметку.

## Порядок
2 → 3 → 4 → 1. После всего — сборка, smoke-тест ролей (баер не видит статистику/историю/удаление), деплой.

## 1. Учётки вместо трёх общих паролей
- Таблица пользователей: логин, пароль (scrypt-хеш), роль `buyer | teamlead | admin`, у баера — его тимлид (`teamlead_id`), флаг активности.
- Создаёт и редактирует учётки **только админ** в интерфейсе (страница «Пользователи»: создать, сменить роль/тимлида, сбросить пароль, отключить). Саморегистрации нет.
- Первый админ — из `.env` (`VSL_STAT_ADMIN_LOGIN` / `VSL_STAT_ADMIN_PASSWORD`), создаётся при старте, если админов нет.
- **Обе вкладки доступны всем ролям** («Библиотека крео» и «Качество на лендах»). Роль влияет на видимость тегов и на админские действия.
- Только админ: подключение/отключение Google Drive, управление учётками.
- Сессия — подписанная cookie как сейчас, но с `user_id`; смена пароля/отключение учётки выкидывает её сессии.
- Старые `VSL_STAT_PASSWORD*` и роли `full/library/quality` убрать (`server/http/auth.ts`, `channelArea()` в `server/http/app.ts`, guard'ы в `src/app/app.routes.ts`).

## 2. Свободные теги на крео
- Тег принадлежит пользователю, который его создал: название (+ цвет). Баер вешает свои теги на любые крео («в работе», «на тест», «залил КО»…).
- Видимость: **баер** — только свои теги; **тимлид** — свои + теги своих баеров; **админ** — все. Проверять на сервере, не только в UI.
- На карточке — чипы видимых тегов (у чужих — подпись владельца). Фильтр «Тег» рядом с «Гео»/«Язык».
- Управление: создать/переименовать/удалить свой тег; повесить/снять на карточке и в диалоге крео.

## 3. Уникальный ID крео
- Формат **`<код вертикали>-<номер>`**, например `SUS-0142`. Номер — сквозной в пределах вертикали, 4 цифры с ведущими нулями (дальше просто растёт).
- Код вертикали — 3 латинские буквы, по умолчанию транслит начала названия папки (Суставы→SUS, Диабет→DIA, Невропатия→NEV…); коллизии (Гипертония/Гипопотенция) — админ правит коды на странице вертикалей. Код фиксируется при первом присвоении.
- Присваивается автоматически каждому крео (всем ~600 существующим — миграцией, по дате добавления на Drive) и новым при синхронизации/загрузке. **Никогда не меняется**, даже если крео перенесли в другую папку. Файлы на Drive не переименовываем.
- В UI ID — крупно и заметно на карточке и в диалоге, с кнопкой «скопировать». Имя файла — мелко внизу.
- Использование: баер переносит ID в Кайтен и в название кампании FB.

## 4. Вертикаль слева → сразу список
- Боковая панель — **вертикали (папки Drive)**, клик → плоский список крео этой вертикали.
- Переключатель «По группам / По папкам / Списком» убрать. Ручные группы как сущность больше не нужны (их роль закрывают вертикали + теги) — убрать из UI.
- Счётчики «+N новых», фильтры Гео/Язык/Новые за — остаются и работают в рамках выбранной вертикали.
